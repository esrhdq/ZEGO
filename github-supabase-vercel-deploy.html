재고관리 프로그램 배포 가이드

GitHub 저장소 등록 → Supabase(PostgreSQL) → Vercel 호스팅 → 환경 변수로 IP 화이트리스트 설정 순서입니다. 이 파일은 프로젝트 문서용으로 저장소에 함께 올리면 됩니다.

0 이 안내 파일 위치

저장소 안에서 아래 경로에 있습니다. 탐색기에서 더블 클릭하면 브라우저로 열 수 있습니다.

inventory_app/docs/github-supabase-vercel-deploy.html

GitHub에는 전체 inventory_app 폴더를 올리는 것을 권장합니다. (vercel.json, api/index.py, app.py가 같은 루트에 있어야 합니다.)

1 GitHub에 등록

  1. GitHub에서 New repository로 빈 저장소를 만듭니다. (README는 선택)
  2. PC에서 터미널을 열고, 앱이 있는 폴더로 이동합니다.

저장소 루트가 inventory_app 내용인 경우:

cd 경로\inventory_app
git init
git add .
git commit -m "Initial commit: inventory app"
git branch -M main
git remote add origin https://github.com/본인아이디/저장소이름.git
git push -u origin main

상위 폴더(data 등) 전체를 올리는 경우, Vercel에서 Root Directory를 inventory_app으로 지정하면 됩니다.

주의: .env 파일은 .gitignore에 있으므로 커밋되지 않습니다. 비밀 정보는 GitHub에 올리지 마세요.

2 Supabase 준비

  1. Supabase에서 새 프로젝트를 만듭니다.
  2. Settings → Database에서 연결 문자열을 복사합니다. 서버리스(Vercel)에는 보통 Transaction pooler(포트 6543) 연결 문자열을 권장합니다.
  3. 앱은 배포 시 DATABASE_URL이 설정되어 있으면 PostgreSQL을 사용하고, 없으면 SQLite를 씁니다. Vercel 배포에서는 반드시 DATABASE_URL을 넣으세요.
  4. 첫 요청 시 api/index.py에서 init_db()가 호출되어 테이블 생성·초기 데이터가 들어갑니다. (이미 테이블이 있으면 스킵되는 부분이 많습니다.)

IPv4 전용 네트워크에서 연결이 안 되면 Supabase 대시보드에서 IPv4 애드온 등 문서를 확인하세요.

3 Vercel에 연결

  1. Vercel에 로그인 후 Add New → Project에서 방금 만든 GitHub 저장소를 import합니다.
  2. 저장소 구조에 따라 Root Directory를 inventory_app으로 설정합니다. (저장소 루트가 이미 inventory_app이면 비워둬도 됩니다.)
  3. Environment Variables에 아래를 추가합니다. (Production 기준)
이름설명
DATABASE_URLSupabase PostgreSQL 연결 문자열 (pooler 권장)
SECRET_KEY긴 임의 문자열 (세션 암호화). 로컬과 다르게 새로 생성 권장
ALLOWED_IPS허용할 공인 IP만 쉼표로 구분. 예: 203.0.113.10,198.51.100.2

환경 변수 저장 후 Redeploy해야 반영되는 경우가 있습니다.

4 IP 화이트리스트 (ALLOWED_IPS)

앱은 ALLOWED_IPS가 비어 있지 않으면, 요청마다 클라이언트 IP를 검사합니다. Vercel 앞단 프록시 뒤에서는 X-Forwarded-For의 첫 번째 IP를 사용합니다.

  • 형식: IP1,IP2,IP3 (공백은 각 항목의 앞뒤에서 제거됨)
  • 사무실·집 등 고정 출구 IP를 넣는 방식이 일반적입니다. (휴대폰 LTE 등은 IP가 바뀔 수 있음)
  • 화이트리스트에 없으면 403 페이지가 표시됩니다.
  • 로컬에서 Flask만 돌릴 때도 제한을 쓰려면 목록에 127.0.0.1을 포함해야 할 수 있습니다.
  • IPv6로 접속하는 경우 해당 형식의 주소도 목록에 넣어야 할 수 있습니다.

전체 공개가 필요한 잠깐의 테스트는 Vercel에서 ALLOWED_IPS를 비우면 됩니다. 운영 전에 반드시 다시 제한하세요.

5 배포 후 확인

  1. Vercel이 준 프로덕션 URL로 접속합니다.
  2. IP가 허용 목록에 있으면 로그인 화면이 보여야 합니다.
  3. 기본 관리자(초기 시드): 사용자명 admin, 비밀번호는 코드에 정의된 초기값입니다. 첫 로그인 후 반드시 비밀번호를 변경하세요.
