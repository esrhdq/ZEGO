01 · 시작하기
로그인
ZEGO는 인터넷 브라우저에서 사용합니다. 아이디와 비밀번호를 입력하면 바로 시작할 수 있어요.
1
브라우저 주소창에 ZEGO 주소 입력
zego-blue.vercel.app 을 입력하고 Enter를 누르세요.
2
아이디 입력
담당자에게 받은 아이디를 입력합니다. (예: icn, gmp)
3
비밀번호 입력
비밀번호를 입력합니다. 처음 발급된 초기 비밀번호는 $eastar12입니다.
4
로그인 버튼 클릭
빨간 로그인 버튼을 클릭합니다.
5
초기 비밀번호 변경 (최초 1회)
초기 비밀번호로 로그인하면 자동으로 비밀번호 변경 화면이 나타납니다. 새 비밀번호를 설정해야 대시보드로 이동할 수 있어요.
초기 비밀번호는 $eastar12입니다. 첫 로그인 시 반드시 본인만 아는 비밀번호로 바꿔주세요.
비밀번호를 5번 이상 틀리면 계정이 잠깁니다. 잠긴 경우 관리자에게 문의하세요.
30분 동안 아무것도 안 하면 자동으로 로그아웃됩니다. 중요한 작업 중이라면 주기적으로 저장하세요.

재고 부족 경고 확인

왼쪽 메뉴로 이동

03 · 재고 현황
지금 재고 얼마나 있나요?
우리 지점에 어떤 양식이 몇 개 있는지 확인합니다. 색깔로 상태를 바로 알 수 있어요.
1
왼쪽 메뉴 → 재고 현황 클릭

2
재고 상태 색깔 확인
충분 초록색: 재고가 넉넉합니다.
부족 노란색: 최소 기준보다 적습니다.
없음 빨간색: 재고가 0개입니다.
3
검색으로 빠르게 찾기
양식 이름을 검색창에 입력하면 원하는 항목만 바로 찾을 수 있어요.
관리자는 모든 지점의 재고를 볼 수 있습니다. 지점 직원은 자신의 지점만 보입니다.

07 · 이관

처리 섹션의 이관을 클릭합니다.
2
받을 지점 선택

🟠 이관 요청 받았을 때 (다른 지점에서 요청이 왔을 때)
1
알림 배지 확인
이관 요청이 오면 왼쪽 메뉴의 이관 옆에 숫자 배지가 표시됩니다.
2
요청 내용 확인
어느 지점에서, 어떤 양식을, 몇 개 요청했는지 확인합니다.
3
승인 또는 거절
보낼 수 있으면 승인, 재고가 없으면 거절을 클릭합니다. 거절 시에는 사유를 입력해야 합니다.
이관 요청이 승인 또는 거절되면 신청 지점에 이메일로 결과가 안내됩니다.
내가 신청한 이관 내역은 왼쪽 메뉴 내 이관 내역에서 확인할 수 있어요.

11 · 운송양식 신청

📋 운송양식 신청 처리

메뉴: 관리자 → 운송양식 신청 관리
📅 운송양식 신청기간 설정
운송양식 신청 가능 기간을 설정합니다. 기간 외에는 지점에서 신청할 수 없어요.
메뉴: 관리자 → 신청 기간 설정
🗓️ 운송아이템 신청기간 설정
카탈로그 아이템 신청 가능 기간을 설정합니다. 기간 외에는 장바구니 담기와 신청 제출이 모두 차단됩니다.
메뉴: 관리자 → 운송아이템 신청기간
✉️ 지점 이메일 관리
각 지점의 담당자 이메일을 등록합니다. 신청 처리 결과 안내 메일이 여기 등록된 주소로 발송됩니다.
메뉴: 관리자 → 지점 이메일 관리
✅ 운송양식 신청 승인 / 반려 방법
1
메뉴 → 운송양식 신청 관리

승인 또는 반려 클릭

비밀번호 변경하기
초기 비밀번호($eastar12)로 첫 로그인하면 자동으로 변경 화면이 표시됩니다. 이후에는 180일(약 6개월)마다 바꿔야 하며, 기간이 지나도 로그인 시 바로 변경 화면이 나타나요.
신규 계정의 초기 비밀번호는 $eastar12입니다. 첫 로그인 시 강제로 변경 화면이 나타나며, 변경 완료 전까지는 다른 메뉴를 사용할 수 없습니다.
1
왼쪽 메뉴 최하단 → 비밀번호 변경
사이드바 맨 아래 비밀번호 변경을 클릭합니다. (최초 로그인 시에는 자동으로 이동됩니다.)
2
현재 비밀번호 입력
지금 쓰고 있는 비밀번호를 입력합니다. (처음이라면 $eastar12)
3
새 비밀번호 두 번 입력
새 비밀번호를 입력하고, 확인을 위해 한 번 더 똑같이 입력합니다.
4
변경 완료
비밀번호 변경 버튼을 클릭하면 즉시 적용됩니다.
비밀번호를 잊어버렸다면 관리자에게 초기화를 요청하세요. 초기화 시 $eastar12로 리셋되며 다시 변경이 강제됩니다.
