1. 시스템 소개

ZEGO는 이스타항공 전 지점의 운송양식 및 비품(운송아이템) 재고를 통합 관리하는 웹 기반 시스템입니다. 국내·국제·화물 지점 담당자와 본사 관리자가 함께 사용합니다.

주요 기능
  • 재고 관리 — 입고·출고·지점 간 이전, 실시간 재고 현황
  • 운송양식 비품 신청 — 지점에서 양식 소모품 신청, 관리자 승인
  • 운송아이템 카탈로그 신청 — X-배너, 스탠션 등 비품 온라인 신청
  • 보고서 & 수요예측 — 월별 소비 분석, 재고 소진 예측
  • 다국어 지원 — 한국어, English, 日本語, 中文(简体), 中文(繁體)

ℹ 비밀번호 만료 7일 전부터 상단에 경고 메시지가 표시됩니다. 기간 내 변경하세요.
언어 설정

우측 상단 언어 드롭다운에서 원하는 언어를 선택하면 즉시 전환됩니다.

4. 재고현황

좌측 메뉴 재고현황을 클릭합니다. 4개의 탭으로 구성되어 있습니다.

탭 1 — 지점별 상세

모든 지점·양식 조합의 현재 재고를 테이블로 표시합니다.

  • 필터: 지점, 양식 종류로 좁혀서 조회 가능
  • 최소기준 수정: 수량 옆 입력창에 숫자 입력 후 Enter — 해당 지점만 저장
  • 엑셀 다운로드: 현재 필터 조건으로 엑셀 파일 다운로드
탭 2 — 지점별 보기 관리자

각 지점을 아코디언 패널로 펼쳐서 해당 지점 내 모든 양식 재고를 확인합니다.

  • 소진/부족 현황이 각 지점 헤더에 요약 표시됩니다
  • 지점별로 최소기준을 별도 설정할 수 있습니다
탭 3 — 양식별 누적 합계

양식 종류별로 전체 지점 합계 재고를 확인합니다.

  • 지점 수 버튼 클릭 시 해당 양식을 보유한 지점별 상세 팝업
  • 부족 지점 수, 소진 지점 수 표시
탭 4 — 월별 소비 현황

최근 6개월간 양식별 출고 수량 추이를 확인합니다.

💡 최소기준은 지점별로 독립 관리됩니다. 한 지점의 최소기준을 변경해도 다른 지점에 영향을 주지 않습니다.
5. 입고 처리

본사 또는 외부에서 양식을 수령했을 때 처리합니다.

1
좌측 메뉴 입고 처리 클릭
2
지점 선택 (관리자만, 지점 계정은 자동 설정)
3
양식 종류, 수량, 날짜, 비고 입력
4
입고 처리 버튼 클릭
ℹ 입고 후에도 해당 지점의 재고가 최소기준 이하인 경우 자동으로 알림이 생성됩니다.
6. 출고 처리

양식을 실제로 사용하거나 외부로 내보낼 때 처리합니다.

1
좌측 메뉴 출고 처리 클릭
2
지점, 양식 종류, 수량, 날짜, 비고 입력
3
출고 처리 버튼 클릭
⚠ 현재 재고보다 많은 수량은 출고할 수 없습니다. 출고 후 재고가 최소기준 이하로 떨어지면 자동 알림이 발송됩니다.
7. 일괄 출고

여러 양식을 한 번에 출고할 때 사용합니다.

1
좌측 메뉴 일괄 출고 클릭
2
지점 선택 후 해당 지점의 양식 목록이 표시됨
3
각 양식의 출고 수량 입력 (0이면 건너뜀)
4
날짜, 공통 비고 입력 후 일괄 출고 버튼 클릭
💡 한 번의 작업으로 여러 양식을 동시에 출고 처리하여 시간을 절약할 수 있습니다.
8. 지점 간 이전

재고가 부족한 지점에서 여유가 있는 지점에 이전을 요청할 때 사용합니다.

이전 신청 (지점 계정)
1
좌측 메뉴 지점 간 이전 클릭
2
출발 지점(자동), 도착 지점, 양식, 수량, 날짜 입력
3
이전 신청 버튼 클릭 → 승인 대기 상태
ℹ 이전 신청을 받은 지점에는 메일로 안내됩니다. ZEGO 사이트에 접속하여 처리해주세요. 처리가 완료되면 이전 신청을 요청한 지점에 처리 결과가 메일로 안내됩니다.
이전 확인 지점

승인된 이전 건은 받는 지점에서 확인(Confirm) 처리해야 재고가 최종 반영됩니다.

이전 상태 흐름
상태의미
대기 (Pending)관리자 승인 전
승인 (Approved)관리자가 승인, 받는 지점의 확인 대기
확인 (Confirmed)이전 완료, 재고 반영
거부 (Rejected)관리자가 거부
나의 이전 신청 내역

지점 계정은 나의 이전 신청 메뉴에서 본인 지점의 이전 내역을 확인할 수 있습니다.

9. 거래 내역 & 보고서
거래 내역

모든 입고·출고·이전 내역을 조회합니다. 지점, 양식, 거래 유형, 기간으로 필터링 가능합니다.

보고서

다양한 통계 차트로 재고 현황을 분석합니다.

  • 지점별 재고 현황 (정상/부족/소진 비율)
  • 월별 입고·출고 비교
  • 양식별 상위 출고 현황
  • 지점별 재고 수량 차트
수요예측

과거 출고 패턴을 분석하여 향후 재고 소진 예상일을 계산합니다. 미리 입고 계획을 수립하는 데 활용하세요.

운항스케줄

이스타항공 운항 스케줄을 조회하여 비품 준비 계획을 수립할 수 있습니다.

10. 카탈로그 (운송아이템) 신청

X-배너, 스탠션, 안내 도구 등 운송 비품을 온라인으로 신청합니다.

신청 방법
1
좌측 메뉴 카탈로그 클릭 — 품목 목록 확인
2
원하는 품목에서 수량 입력 후 담기 버튼 클릭
3
신청 장바구니 메뉴에서 최종 확인 후 신청 완료
4
신청 내역 메뉴에서 진행 상황 확인
ℹ 카탈로그 신청은 관리자가 설정한 신청 기간 내에만 가능합니다. 기간이 닫혀 있으면 신청 버튼이 비활성화됩니다.
신청 상태
상태의미
대기관리자 검토 중
승인처리 예정
확인배송/지급 완료
거부신청 거부
11. 양식 비품 신청

지점에서 운송양식 소모품을 본사에 신청할 때 사용합니다.

신청 방법
1
좌측 메뉴 양식 신청 클릭
2
양식 종류, 신청 수량, 비고 입력
3
신청 버튼 클릭
4
나의 신청 내역에서 처리 상황 확인
ℹ 양식 신청도 관리자가 설정한 신청 기간 내에만 가능합니다.
12. 관리자 기능 관리자 전용
사용자 관리
  • 사용자 계정 생성·수정·삭제
  • 역할 설정: 관리자(admin) / 지점(branch)
  • 지점 배정
  • 비밀번호 초기화
양식 신청 관리

지점에서 신청한 양식 비품 신청 건을 확인하고 승인/거부합니다. 미처리 건수는 메뉴 옆 배지로 표시됩니다.

신청 기간 설정

신청 기간 설정 메뉴에는 두 개의 탭이 있습니다:

  • 운송양식 탭: 양식 비품 신청 기간 설정
  • 운송아이템 탭: 카탈로그 신청 기간 설정

각 탭에서 기간 제목, 시작일, 종료일, 활성화 여부를 설정합니다. 역대 기간 이력도 확인 가능합니다.

지점 이메일 설정

이전 승인·거부 등 중요 알림 이메일을 받을 지점별 담당자 이메일을 설정합니다.

접속 로그

전체 사용자의 로그인·로그아웃 이력을 확인합니다.

재고현황 지점별 보기

관리자 계정에서만 표시되는 지점별 보기 탭에서 각 지점의 재고를 아코디언 방식으로 확인합니다.
