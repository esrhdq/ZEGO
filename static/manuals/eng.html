1. System Overview

ZEGO is a web-based system for integrated management of transport forms and supplies (transport items) across all Eastar Jet branches. Branch staff and HQ administrators use it together.

Key Features
  • Inventory Management — Inbound, outbound, branch transfers, real-time stock status
  • Form Supply Requests — Branches request consumable forms, administrators approve
  • Catalog (Transport Items) Requests — Online requests for X-banners, stanchions, etc.
  • Reports & Demand Forecasting — Monthly consumption analysis, depletion prediction
  • Multi-language Support — Korean, English, Japanese, Simplified Chinese, Traditional Chinese

2. Login & Password

4. Inventory Status

Click Inventory in the left menu. There are 4 tabs.

Tab 1 — Branch Detail

Displays current stock for all branch-form combinations in a table.

  • Filter: Narrow results by branch or form type
  • Edit Minimum Threshold: Type a number in the input field and press Enter — saves for that branch only
  • Excel Download: Download an Excel file with current filter conditions
Tab 2 — Branch View Admin

Each branch is displayed as an accordion panel showing all its form stock.

  • Empty/low stock counts are summarized in each branch header
  • Minimum thresholds can be set per-branch independently
Tab 3 — Form Summary

See total stock across all branches, grouped by form type.

  • Click the branch count button to see a popup with per-branch details
  • Low branch count and empty branch count are shown
Tab 4 — Monthly Consumption

View monthly outbound quantity trends for each form over the past 6 months.

💡 Minimum thresholds are managed per branch. Changing one branch's threshold does not affect other branches.
5. Inbound Processing

Use this when you receive forms from HQ or an external source.

1
Click Inbound in the left menu
2
Select branch (admin only; branch accounts are set automatically)
3
Enter form type, quantity, date, and notes
4
Click the Process Inbound button
ℹ If stock remains below the minimum threshold after inbound, an alert is automatically generated.
6. Outbound Processing

Use this when forms are consumed or sent out.

1
Click Outbound in the left menu
2
Enter branch, form type, quantity, date, and notes
3
Click the Process Outbound button
⚠ You cannot process an outbound for more than the current stock quantity. An alert is sent automatically if stock falls to or below the minimum threshold after outbound.
7. Bulk Outbound

Process multiple forms at once in a single operation.

1
Click Bulk Outbound in the left menu
2
Select branch — the form list for that branch appears
3
Enter outbound quantity for each form (leave 0 to skip)
4
Enter date and shared notes, then click Bulk Outbound
💡 Save time by processing multiple forms simultaneously in a single submission.
8. Branch-to-Branch Transfer

Transfer forms from a branch with surplus stock to one with insufficient stock.

Requesting a Transfer (Branch Account)
1
Click Branch Transfer in the left menu
2
Your branch is set as origin; select destination branch, form, quantity, and date
3
Click Request Transfer → status becomes "Pending"
Approving / Rejecting Transfers Admin

Admins review requests in the Received Requests tab of the Branch Transfer menu and approve or reject them. Approval automatically moves the stock.

Confirming a Transfer Branch

The receiving branch must click Confirm for the stock to be finally reflected in inventory.

Transfer Status Flow
StatusMeaning
PendingAwaiting admin approval
ApprovedApproved by admin; awaiting receiving branch confirmation
ConfirmedTransfer complete; inventory updated
RejectedRejected by admin
My Transfer Requests

Branch accounts can view their transfer history in the My Transfer Requests menu.

9. Transaction History & Reports
Transaction History

View all inbound, outbound, and transfer records. Filter by branch, form type, transaction type, and date range.

Reports

Analyze inventory with various statistical charts:

  • Branch-level stock status (Normal / Low / Empty ratios)
  • Monthly inbound vs. outbound comparison
  • Top outbound forms by form type
  • Branch stock quantity chart
Demand Forecasting

Analyzes historical outbound patterns to estimate future depletion dates. Use this to plan inbound orders in advance.

Flight Schedule

View the Eastar Jet flight schedule to help plan supply preparations.

10. Catalog (Transport Items) Request

Request transport supplies such as X-banners, stanchions, and guidance tools online.

How to Request
1
Click Catalog in the left menu — view the item list
2
Enter quantity and click Add to Cart for each item
3
Go to Request Cart, review, and click Submit Request
4
Check progress in Request History
ℹ Catalog requests are only possible during the request period set by the administrator. If the period is closed, the request button is disabled.

11. Form Supply Request

Branches use this to request consumable transport forms from HQ.

How to Request
1
Click Form Request in the left menu
2
Select form type, enter quantity and notes
3
Click the Submit button
4
Track progress in My Requests
ℹ Form supply requests are also subject to the request period configured by the administrator.
12. Admin Functions Admin Only
User Management
  • Create, edit, and delete user accounts
  • Set roles: Admin or Branch
  • Assign branch
  • Reset passwords
Form Request Management

Review, approve, or reject form supply requests submitted by branches. Pending count shown as a badge on the menu.

Request Period Settings

The Request Period Settings menu has two tabs:

  • Transport Forms tab: Set the form supply request period
  • Transport Items tab: Set the catalog request period

In each tab, configure the period title, start date, end date, and enabled/disabled status. Historical periods are also viewable.

Branch Email Settings

Set the contact email per branch for important notifications (transfer approvals, rejections, etc.).

Access Logs

View login and logout history for all users.

Branch View in Inventory

The Branch View tab (admin only) shows each branch's stock in accordion-style panels.
